# 💣 지뢰찾기

회색 입체 버튼과 디지털 카운터를 살린 클래식 윈도우 스타일의 브라우저 지뢰찾기입니다. 왼쪽 클릭으로 칸을 열고, 오른쪽 클릭으로 깃발을 표시하세요. 숫자는 주변 8칸에 있는 지뢰의 수를 알려줍니다. 지뢰가 없는 모든 칸을 열면 승리합니다.

## 실행 방법

저장소의 `index.html`을 최신 웹 브라우저에서 열면 바로 플레이할 수 있습니다. `style.css`와 `script.js`도 같은 폴더에 두세요. 빌드나 별도 패키지 설치는 필요하지 않습니다.

## 기능

- 초급(9×9, 지뢰 10개), 중급(16×16, 지뢰 40개), 고급(30×16, 지뢰 99개) 난이도
- 가로 5~30칸, 세로 5~24칸으로 직접 설정하는 커스텀 게임
- 첫 번째로 여는 칸은 항상 안전하며, 빈 칸은 인접한 안전 구역까지 자동으로 열립니다.
- 남은 지뢰 수, 첫 클릭부터 진행되는 타이머, 게임 상태에 따라 바뀌는 재시작 버튼
- 승리 기록과 진행 중인 게임을 브라우저 로컬 저장소에 자동 보관
- 작은 화면에서도 가로로 스크롤하며 플레이할 수 있는 반응형 게임판

## 구현

게임은 별도 프레임워크나 라이브러리 없이 HTML, CSS, JavaScript로 구현했으며, 화면 구조는 `index.html`, 디자인은 `style.css`, 게임 로직은 `script.js`에 분리했습니다. 지뢰는 첫 칸을 연 뒤 배치되며, 브라우저 로컬 저장소를 사용해 기록과 게임 진행 상황을 보관합니다.
